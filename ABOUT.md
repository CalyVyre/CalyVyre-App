# About the Developer

## Hello! My name is Raza

Hi, I'm **CalyVyre**, the developer of **CalyVyre Affirm**.

## Why I Built This Project

CalyVyre Affirm was created to help traders strengthen discipline, patience, consistency, and trading psychology through daily affirmations and mindset training.

The project began as a personal idea and continues to evolve with each release.

## Development Journey

The public releases document the evolution of the application over time. Each version represents meaningful progress toward building a more complete and polished desktop application.

## Vision

My goal is to create practical desktop applications that help people improve their mindset, decision-making, and consistency.
